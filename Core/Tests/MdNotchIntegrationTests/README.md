# Integration tests (real frozen binary)

Slow suite: converts one committed sample per supported format (plus one
rejected format) through the real PyInstaller binary, via the full
`ConversionPipeline` + `SubprocessMarkdownConverter` stack.

Skipped by default so `swift test` stays fast. Run explicitly with:

```bash
# from Core/, after building the binary (scripts/freeze-markitdown/build.sh)
MDNOTCH_INTEGRATION=1 swift test --filter MdNotchIntegrationTests
```

The binary is located at `scripts/freeze-markitdown/dist/markitdown-bin/`
relative to the repo root; override with `MDNOTCH_MARKITDOWN_BIN=/path/to/bin`.

Samples are generated by `scripts/gen-samples/gen_samples.py` and committed.
